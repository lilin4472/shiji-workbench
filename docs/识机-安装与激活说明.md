# 识机安装与激活说明（Windows x64）

## 体验版

运行 `Shiji-Trial-Setup-0.2.27-r2-x64.exe`，按安装向导完成安装。体验版无需注册、授权码或模型 Key，可在原版界面查看两份标明采集日期的历史项目，并回放各分析模块的历史结果。它不提供实时搜索；历史案例不代表项目当前仍在招标。

## 正式版

1. 运行 `Shiji-Full-Setup-0.2.27-x64.exe`，按安装向导完成安装。
2. 首次打开，复制窗口显示的本机设备码，连同订单编号发给卖家。设备码不是 API Key。
3. 把卖家发回的完整授权码粘贴到激活窗口，点击“验证并启动识机”。验证在本机完成，成功后软件会自动重启。
4. 进入“设置”，按各 Key 输入框旁的申请说明配置自己的 DeepSeek 和豆包搜索 Key，再测试连接。实时搜索会使用你的 Key，相关服务可能按其计费规则扣费。地图功能需要可用的天地图 Key。

每笔订单最多给两台不同电脑签发授权码；两台电脑分别发送各自设备码。重装同一台电脑可用原授权码；更换电脑请联系卖家处理。搜索内容和项目资料保存在本机。

Windows 若提示“未知发布者”，表示当前安装包尚无发布者数字签名。请核对卖家提供的安装包文件名和 SHA-256 校验值；不要从不明链接下载。向他人转发安装包不会转移设备授权。
